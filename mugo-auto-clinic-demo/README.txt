MUGO AUTO CLINIC — LOCAL WEBSITE DEMO
====================================

HOW TO VIEW
1. Extract the ZIP file (if you received the ZIP).
2. Open the mugo-auto-clinic-demo folder.
3. Double-click index.html to open it in your browser.

No installation, build process or server is required.

FILES
- index.html: website content and page structure
- styles.css: responsive layout and visual design
- script.js: mobile navigation and current year
- assets/mugo-original-flyer.jpeg: supplied business flyer for reference

BEFORE GOING LIVE
- Confirm that both contact numbers are correct and which one should be the primary number.
- Confirm the exact service area and whether all listed roadside services are currently offered.
- Confirm the 24/7 availability wording.
- Replace the sample automotive workshop photo with a client-approved photo.
- Connect a domain and hosting, and add any required privacy/legal information.

The website uses the business information supplied in the conversation. The automotive hero image is a remote sample image and needs an internet connection to display. Google Fonts also load online.
